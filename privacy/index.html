Privacy and data scope

boplog is a static public archive hosted on GitHub Pages. It does not provide user accounts, comments, purchases, uploads, or a server-side contact form. The site JavaScript reads checked-in public JSON and may store a theme preference and interface state in the visitor's browser. boplog itself does not operate an application database of visitors.

Published project data

The archive contains metadata about public GitHub repositories where kvnloo authored commits. Typical fields include repository name, public URL, description, date, language, tags, classifications, and evidence links. Private repositories are not intentionally collected or published. Forks without authored commits are excluded, and contribution relationships are labeled to avoid conflating owned work with upstream work.

Hosting and network records

Requests are served by GitHub Pages and its delivery infrastructure. GitHub may process ordinary network and security data under its own terms and privacy statement. boplog does not control GitHub's server logs, CDN headers, retention, or bot-protection behavior. External links lead to services with their own privacy practices.

Corrections and removal requests

If a public record is inaccurate, stale, or exposes information that should not be mirrored here, use the routes on the contact page. Identify the exact URL and field. Public corrections can use a repository issue; sensitive reports should use email. Do not post secrets or private personal information in an issue.

Agent use

Agents may read and summarize the public archive, but should not infer private projects, private clients, funding, home or office addresses, phone numbers, or unpublished plans. Absence from boplog means only that an item is not present in this public snapshot.
