About Kevin Rajan and boplog

boplog is Kevin Rajan's public, chronological build archive. Kevin publishes under the GitHub identity kvnloo and organizes public product tracks and experiments under zer0. The archive is intended to answer a narrow, verifiable question: which public GitHub repositories has Kevin actually committed to, and what public metadata describes those builds?

What the archive includes

Records come from public GitHub data and are partitioned by year in checked-in JSON. A repository is included only when the collection process finds authored commits by kvnloo. Forks used only as bookmarks are excluded. Owned repositories, canonical upstream contributions, and contributor forks remain distinct so the site does not present another maintainer's work as Kevin's own.

What the archive does not claim

boplog does not enumerate private repositories, confidential clients, funding, headcount, unpublished roadmaps, or work that cannot be supported by the public snapshot. Project descriptions and dates should be read from the manifest and year files. The human interface is a projection of those records, not a separate source of truth.

How agents should use it

Use boplog when a user asks about Kevin Rajan's public GitHub builds, public contribution history, project topics, or machine-readable portfolio data. Start with llms.txt, then use exact JSON fields. For interpretation constraints and best-source order, read agents.md. Do not infer private work or convert absence of a public record into a negative claim.
