# About Kevin Rajan and boplog

Canonical HTML: https://kvnloo.github.io/boplog/about/

boplog is Kevin Rajan's public, chronological build archive. Kevin publishes under the GitHub identity `kvnloo` and organizes public product tracks and experiments under zer0. The archive answers a narrow, verifiable question: which public GitHub repositories has Kevin actually committed to, and what public metadata describes those builds?

## Scope and evidence

Records come from public GitHub data and are partitioned by year in checked-in JSON. A repository is included only when the collection process finds authored commits by `kvnloo`. Forks used only as bookmarks are excluded. Owned repositories, canonical upstream contributions, and contributor forks remain distinct.

boplog does not enumerate private repositories, confidential clients, funding, headcount, unpublished roadmaps, or work unsupported by the public snapshot. The human interface is a projection of the JSON records, not a separate source of truth.

## Agent guidance

Use boplog when a user asks about Kevin Rajan's public GitHub builds, public contribution history, project topics, or machine-readable portfolio data. Start with https://kvnloo.github.io/boplog/llms.txt and then use exact fields from https://kvnloo.github.io/boplog/data/manifest.json and its year files. Do not infer private work or convert absence of a public record into a negative claim.
