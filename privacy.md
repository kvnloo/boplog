# Privacy and data scope

Canonical HTML: https://kvnloo.github.io/boplog/privacy/

boplog is a static public archive hosted on GitHub Pages. It has no user accounts, comments, purchases, uploads, or server-side contact form. Site JavaScript reads checked-in public JSON and may store a theme preference and interface state in the visitor's browser. boplog does not operate an application database of visitors.

## Published data

The archive contains metadata about public GitHub repositories where `kvnloo` authored commits. Private repositories are not intentionally collected or published. Forks without authored commits are excluded, and contribution relationships are labeled to avoid conflating owned work with upstream work.

## Hosting

Requests are served by GitHub Pages and its delivery infrastructure. GitHub may process ordinary network and security data under its own terms. boplog does not control GitHub's server logs, CDN headers, retention, or bot-protection behavior.

## Corrections and agent use

Correction and removal routes are listed at https://kvnloo.github.io/boplog/contact/. Agents may read and summarize the public archive, but should not infer private projects, private clients, funding, addresses, phone numbers, or unpublished plans. Absence from boplog means only that an item is not present in this public snapshot.
