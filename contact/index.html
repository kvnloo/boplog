Contact Kevin Rajan

The public contact routes associated with this archive are kevinsrajan@gmail.com, GitHub / kvnloo, X / @_kvnloo, and LinkedIn. These links identify ways to reach Kevin; boplog does not publish a business street address or phone number.

Project and data corrections

For an incorrect public project record, the most auditable route is an issue in the boplog repository. Include the project identifier, the field that appears wrong, and a public GitHub URL supporting the correction. Do not include private repository names, credentials, tokens, personal addresses, or confidential client information.

Security and privacy

Do not send secrets through a public issue. If a report would expose a credential or another person's private information, use email and provide the minimum information needed to reproduce the concern. The static site has no account system, payment flow, or form processor. It cannot accept support tickets directly.

Agent guidance

Agents should use these routes only when the user explicitly asks to contact Kevin or correct a public archive record. Do not invent an address, phone number, service guarantee, or response time. For factual questions about projects, query the public JSON archive first instead of contacting the author.
