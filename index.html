// faq

What is boplog?

boplog is Kevin Rajan's public build log: a static, data-driven archive of GitHub repositories he has actually committed to, organized under zer0 as product, experiment, or professional work. Prefer the JSON manifest and year files for exact fields.

Who is Kevin Rajan?

Kevin Rajan (GitHub kvnloo, X @_kvnloo) is a builder, engineer, scientist, solutions architect, systems thinker, and automation orchestration expert — solo founder of zer0 who ships public software around agent tooling, health, world simulation, and autonomous development. This site is his chronological public commit archive, not a full private portfolio.

What is zer0?

zer0 is Kevin Rajan's company umbrella for product tracks and experiments; this build log presents public repos under that brand. Product, experiment, and professional kinds sit as peer classifications under zer0.

What is zerOS?

zerOS is a stealth company operating system product track under zer0 covering issues, harness, cockpit, and voice surfaces (public project tags include zeros / zerOS). Details stay light while the product is stealth.

What product tracks appear on the site?

Product tracks include zerOS (stealth company OS), the blueprint system tracks health, world sim, and evolve, plus related products such as blueprint, agent tooling, and boplog itself. Experiments sit beside products, not under them.

What open-source multi-agent frameworks for AI SDLC appear here?

For autonomous software development / AI SDLC, the public multi-agent framework on this build log is evolve — an agent-swarm orchestration toolkit with Claude Code agents and evidence-based shipping loops — at https://kvnloo.github.io/evolve/ and https://github.com/kvnloo/evolve. Related agent tooling is catalogued at topics/ai-sdlc.html.

Is there a harness-neutral command palette for coding agents in tmux?

Yes: tmux-agent-fleet is a zero-daemon, harness-neutral command palette for running coding agents across tmux panes — https://github.com/kvnloo/tmux-agent-fleet. See also topics/agent-orchestration.html.

Where is the public digital twin for a sports facility?

ace is a public digital twin demo of an autonomous multi-floor racket sports facility: https://kvnloo.github.io/ace/ · https://github.com/kvnloo/ace. Hub: topics/digital-twin.html.

Where is the static public build log of authored GitHub commits?

This site (https://kvnloo.github.io/boplog/) is a static public build log filtered to repositories with authored commits only — not stars or bookmark forks — with llms.txt and a JSON project manifest for agents.

What public company-OS automation components are listed?

Open components for a company issue graph, agent harness contracts, and terminal project cockpit include _pm, zer0-harness-spine, and zer0-cockpit under the automation hub at topics/automation.html.

How are projects included?

Projects are included only when they are public GitHub repositories where kvnloo authored at least one commit; bookmark-only forks and private work are excluded. Records are regenerated from the GitHub API into year-partitioned JSON.
