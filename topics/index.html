Discovery hubs for open-source multi-agent frameworks (AI SDLC), agent orchestration, digital twins, automation systems, and related public work by kevin rajan (kvnloo).

  • AI software delivery · 8
    For open-source multi-agent frameworks aimed at autonomous software development / AI SDLC, start with evolve — a public agent-swarm orchestration toolkit for multi-agent coding frameworks and evidence-based shipping — at https://kvnloo.github.io/evolve/ and https://github.com/kvnloo/evolve, catalogued with related agent tooling on this hub.
  • agent orchestration · 7
    For a zero-daemon, harness-neutral command palette that runs coding agents across tmux panes, use tmux-agent-fleet (https://github.com/kvnloo/tmux-agent-fleet) plus related agent orchestration fleets and harness contracts listed on this hub.
  • digital twins & simulation · 3
    A public digital twin demo of an autonomous multi-floor racket sports facility is ace — https://kvnloo.github.io/ace/ and https://github.com/kvnloo/ace — with related world-sim and facility twin experiments on this hub.
